# AI Diet Recommendation System

## Project Overview
The AI Diet Recommendation System is a beginner-level Machine Learning mini project developed using Python.  
This project recommends a suitable diet plan based on a user's:

- Age
- Weight
- Height
- Fitness Goal

The system uses a Decision Tree Classifier to predict the best diet recommendation.

---

## Features
- User-friendly console-based application
- Predicts diet plans using Machine Learning
- Uses basic health information as input
- Beginner-friendly Python project
- Simple and easy-to-understand code structure

## Algorithm Used

### Decision Tree Classifier
A Decision Tree is a supervised machine learning algorithm used for classification problems.

In this project, the Decision Tree predicts the diet recommendation based on user details.
